# Connection Guide

## QMK — wired Corne (crkbd / keebv2)

- **Userspace keymap:** `keyboards/crkbd/keymaps/keebv2/`
- **Build tree:** `$env:USERPROFILE\qmk_firmware` (override with `scripts/flash-keebv2.ps1 -QmkPath`)
- **Compile:** `qmk compile -kb crkbd -km keebv2` (flash script copies the userspace keymap first)
- **Flash (Pro Micro / ATmega32U4):** avrdude `avr109`, left default `COM5`, right default `COM6` (confirm in Device Manager; ports move)
- **Remap:** VIA over USB HID. Live snapshot: `layouts/via/crkbd.layout.2026-05-10.json`
- **Not wireless.** Soft serial on D2, `MASTER_LEFT`, TRRS.
